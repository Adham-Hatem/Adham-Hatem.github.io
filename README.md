# React + Vite Portfolio

This project is a React portfolio built with Vite and containerized with Docker for deployment to Hugging Face Spaces.

## Build & Development

- Build: `npm run build`
- Dev: `npm run dev`
- Preview: `npm preview`

## Docker Deployment

See [DOCKER-DEPLOYMENT.md](DOCKER-DEPLOYMENT.md) for complete deployment instructions to Hugging Face Spaces.
